## 📌 Instrucciones de Reporte Obligatorio para el Equipo

Para asegurar una trazabilidad impecable del proyecto y cumplir con las exigencias del hackathon, todo el equipo debe seguir este proceso de documentación:

1. **Reporte Diario en Discord:** Al finalizar cada jornada o reunión de sincronización, cada integrante debe dejar un reporte rápido en su respectivo hilo de rol respondiendo a lo siguiente:
   * **¿Qué hice?:** (Avance técnico o tarea completada).
   * **¿Cuál fue el resultado?:** (Entregable, código probado o avance en el tablero).
   * **¿Qué problemas tuve?:** (Bloqueos, errores de compilación, dudas técnicas).
   * **¿Cuál fue la solución?:** (Cómo se resolvió o si requiere ayuda del equipo/PM).

2. **Actualización Semanal de la Bitácora:** Se debe actualizar este archivo `.md` en **coordinación directa con el Project Manager**, registrando únicamente los hitos, decisiones y resultados **más relevantes de cada sprint**, sin necesidad de duplicar todo el cronograma operativo detallado.
